What a finding looks like

An excerpt from a recent affiliate link teardown, with the site anonymised.

Link 1 — men’s boot, “Buy at REI”

DEAD

Redirects to the affiliate network’s error page: “we no longer advertise for REI.com.” The page then lists ten unrelated merchants, none selling the reviewed boot.

Link 2 — second boot, same post

DEAD

Identical failure. Two of three checked links funnel to the same broken redirect, so this is a pattern from one merchant change, not a one-off.

Link 3 — low-top, same post

INCONCLUSIVE

The request failed outright. Could be a removed link or an automated-request block. Not counted as dead, and flagged for a second check by hand.

LIMITS OF THIS SAMPLE

Three links on one post. Enough to show the pattern, not enough to claim a site-wide rate. Both dead links trace to the same dropped merchant, which may be one event rather than general rot.

The last block is not an afterthought. Every teardown ends with what the sample does not prove, because a finding you cannot check is not worth paying for.
